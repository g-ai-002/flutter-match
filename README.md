# 福运消消乐 🎴

基于 Flutter + Flame 的国风三消闯关游戏，支持 Android、Windows 与 Web。交换相邻棋子、连成三枚同色即可消除，连锁、特殊棋子与破冰目标层层推进，全部内容本地运行，无需联网。

## 功能

- 🎯 经典三消：点选或滑动交换相邻棋子，横竖三连消除，棋盘稳定后自动补位
- 🔗 连锁计分：一次落子可触发多段连锁，连锁越高分数倍率越大
- ✨ 特殊棋子：四连生成横扫/竖贯，拐角 L 形生成爆珠（九宫爆炸），五连生成福珠（交换后消除同类）
- 🧊 冰层机制：厚冰两层、裂冰一层，在冰面上消除即可破冰
- 🗺️ 25 个手工关卡：得分、收集、破冰三类目标，第 21 关起三目标混排，逐关解锁并记录最高分与三星评级
- ⭐ 三星评级：按通关时的剩余步数评定，越快完成越容易拿满三星
- 💡 目标导向提示：优先推荐能推进当前目标的交换，3.5 秒自动收起
- 🛠️ 三种道具：小锤敲掉任意棋子、换位交换任意两枚棋子、洗牌重排棋盘，均不消耗步数
- 💰 福币经济：通关按星级获得福币，局内道具铺购买道具，余额与库存本地持久化
- 📅 每日挑战：按日期确定性地生成关卡与初始棋盘，同一天开局一致，首次通关额外奖励福币
- ♻️ 死局自动重排，重开需二次确认
- 🔊 运行时合成音效：交换、消除、连锁、破冰、胜负各不同，无音频文件入库
- 🎵 五声音阶循环背景音乐，可独立关闭，切后台自动暂停
- 🎨 Flame 棋盘渲染：棋子渐变底纹、单字纹样、选中放大高亮、消除粒子与下落缓动
- ⚡ 流畅度：静止画面整块缓存、底板与贴图复用、绘制零字符串分配，空闲帧只重放一次绘制
- 🖼️ 悬浮 HUD：标题、步数、目标与提示挂在棋盘四周，信息变化不会挪动棋盘
- ⚙️ 逻辑刷新率：30 / 60 / 120Hz 三档（默认 60Hz），固定步长推进动画，低端省电、高刷顺滑
- 🚀 启动轻快：音效与背景音乐在首帧之后于后台 isolate 合成，不阻塞界面出现
- 📱 响应式：手机 / 折叠屏 / 平板 / Windows 窗口自适应，手机窄屏进入关卡自动横屏全屏
- 🌓 深色模式、简体中文、Windows 优先 Microsoft YaHei UI、Web 使用 soup_fonts
- 🧾 日志按天写入用户目录，设置页可查看最近日志
- 🚫 全程离线：无联网、无账号、无广告与内购

## 玩法

1. 点击一枚棋子选中，再点相邻棋子交换；也可以直接向相邻方向滑动。
2. 横竖连成三枚及以上同色棋子即可消除。
3. 在步数用尽前完成关卡目标（得分 / 收集 / 破冰）即可通关。
4. 四连、拐角与五连会生成特殊棋子，善用它们清理冰层与大批棋子。
5. 卡住时用小锤、换位或洗牌道具打开局面；福币不够就先去闯关或打每日挑战。
6. 每日挑战每天一副新棋局，首次通关额外发放 30 福币。

## 开发

```bash
flutter pub get
flutter analyze
flutter test
```

构建产物由 CI 生成：在 GitHub Actions / Gitea Actions 里手动运行 `build` 工作流，选中 `v*` Tag 时按该 Tag 的版本构建 Android / Windows / Web 并发布 Release，运行 `main` 则产出预览产物。音频在运行时合成、Web 字体来自 soup_fonts，仓库不存放字体与音频文件。

## 日志位置

- Windows：`文档/FortuneMatch/logs/app_yyyyMMdd.log`
- Android：应用外部存储目录下的 `FortuneMatch/logs/`
- Web：仅保留内存日志，可在设置页查看

## 目录结构

```
lib/
├── game/       三消引擎、棋盘与连线扫描、动画步骤、计分与提示、道具、每日挑战、关卡配置与控制器
├── flame/      Flame 棋盘组件、排版、棋子视觉、贴图缓存与绘制
├── pages/      首页、关卡选择、对局页、设置页及通用组件
├── services/   日志、偏好与进度存储、运行时音效与音乐合成
├── providers/  用户偏好状态
├── models/     棋子、关卡与目标模型
├── theme/      配色主题与棋子/冰层绘制
└── utils/      常量、格式化、窗口初始化、横屏全屏
```
